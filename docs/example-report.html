如何安全启用一个候选 IP

1查 DHCP 地址池
登录 192.168.1.1，查看地址池起止、当前租约与静态保留。不要只凭扫描结果判断。
2优先做地址保留
把设备 MAC 绑定到指定 IP，让 DHCP 统一管理，避免以后冲突。
3静态配置要避开池
如必须静态，选择地址池外、无保留记录、非网关/DNS/本机的地址，并记录在案。
4配置后再扫描
设置完成后再跑一次本工具，确认该 IP 稳定在线且没有其他设备冲突。

扫描局限与安全边界

  • 只探测 TCP 常见端口，不探测 UDP（如 SNMP、部分 DHCP、mDNS 服务可能漏掉）。
  • ICMP 被防火墙拦截的主机，仍可能通过 ARP 或开放端口被发现；但休眠/关机设备无法被发现。
  • 如果目标不是本机直连网段，ARP 探测无效，结果会明显漏报。
  • 本工具不尝试登录、不猜口令、不利用漏洞；请只扫描你已获授权的网络。
